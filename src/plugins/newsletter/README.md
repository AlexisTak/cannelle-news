# Cannelle Newsletter

MVP de newsletter intégré à EmDash :

- abonnés et liste principale ;
- double opt-in configurable avec jetons hachés ;
- consentements horodatés et désinscription en un clic ;
- campagnes texte, test d'envoi, planification et traitement par lots ;
- import CSV avec preuve de consentement explicite et export CSV ;
- journal de livraison et statistiques de base ;
- webhook signé pour rebonds/plaintes et liste de suppression ;
- API de listes et modèles réutilisables ;
- tableau de bord Block Kit ;
- composant public `CannelleNewsletterSignup.astro` ;
- conversions transmises automatiquement à Cannelle Analytics.

L'envoi s'appuie sur le fournisseur configuré dans le pipeline e-mail EmDash.
